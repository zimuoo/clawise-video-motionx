# Clawise MotionX Implementation Plan

> **For agentic workers:** Use subagent-driven-development to implement isolated tasks with test-first changes and independent review.

**Goal:** Deliver an optimized, branded, standalone Clawise motion skill with its own working installation command, verified video workflow, and a pushed GitHub release source.

**Architecture:** Root zero-dependency Node CLI owns safe installation and packaging. A relocatable skill folder contains its own CLI, studio, deterministic animation runtime, templates, fonts and focused references. Runtime functions are adapted from the MIT upstream snapshot `42360539c10d35397b352461347c073a2966031b`; attribution is retained in legal files, protected likeness and GSAP are excluded.

**Tech Stack:** Node 22+, native ESM/node:test, HTML/CSS/Canvas/Three.js, Chrome DevTools Protocol, FFmpeg, GitHub Actions.

## Task 1 — safe installer and packages

Files: `package.json`, `cli/motionx.js`, `cli/install.js`, `scripts/package.mjs`, `test/install.test.js`, `test/package.test.js`.

- [x] Write failing integration tests with temporary skill/state folders. `installSkill({sourceDir,stateDir})` must place the full skill in `stateDir/skills/clawise-video-motionx`, preserve unrelated files, refuse unowned or edited targets by default, and support managed update/status.
- [x] Implement installer with explicit state-root resolution, validation, atomic replacement and a version/hash ownership marker; provide `--force` only for explicit replacement. No install hooks or model downloads.
- [x] Expose `motionx install`, `motionx update`, `motionx status`, help/version and engine dispatch. Add `npm run pack:skill` to create a relocatable single-skill ZIP and `npm pack --dry-run` validation.
- [x] Test missing/incomplete source, unowned/edited targets, rollback, symlinks and clean packed installation; inspect tar/ZIP contents.

## Task 2 — import, brand and independent timeline

Files: `skills/clawise-video-motionx/engine/{cli,runtime,studio,templates,fonts}`, `test/engine-*`, upstream tests.

- [x] Import only needed MIT/runtime files and fonts; preserve licenses. Remove protected character and author demo/promotional material, remove GSAP files and personal fallback/update paths.
- [x] Write failing deterministic timeline tests before implementing `MotionX.timeline`, `set`, `parseEase`, numeric/plain-object/DOM tweens, labels/position/duration/seek/pause, callback rendering and required transforms. Seeking backwards must reproduce the same state as direct seeking.
- [x] Adapt supported templates/runtime to MotionX; reject unsupported APIs with an actionable error. Keep all assets local, including a new Clawise demo.
- [x] Apply Clawise branding to studio/help/share/export, default signature off and Clawise-only when enabled, state/cache namespaces, and cross-platform Node launchers.
- [x] Run imported/adapted tests and live browser/template tests. Resolve regressions rather than deleting failing coverage.
