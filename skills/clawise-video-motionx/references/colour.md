# 色彩

先从当前产品的真实品牌资产取色，再补充满足对比度的背景与文字色。模板颜色只是起点。

- 一套主背景、主文字和强调色通常足够；需要区分类别时再增加辅助色。
- 颜色有语义：同一对象、状态或类别在全片保持一致。不要只靠颜色表达关键区别，同时使用文字、图形或位置。
- 小文字与背景保持清楚对比；动态背景、叠加素材和透明玻璃要检查实际帧，不能只测静态色值。
- 画面明暗分层：主体、次要信息与装饰有不同强度。避免所有元素都饱和、发光或同样抢眼。
- 品牌色对比不足时调整背景或文字，而不是擅自更改 logo。
- 3D 材质与光照会改变屏幕上的颜色，导出后再检查，不只看 CSS token。

`motionx swatch directions.md` 可把方向中的 Palette 行渲染成色卡。它的 house-look 提示用于发现方案过于雷同，不能覆盖当前用户已确定的品牌色。
