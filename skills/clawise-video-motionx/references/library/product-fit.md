# 根据内容选择语言

| 内容 | 适合的材料和动作 | 验收重点 |
|---|---|---|
| 软件操作 | 真实界面、共享对象、连续镜头 | 输入与结果对应，截图可读 |
| AI 或开发工具 | 实际输入、处理过程、具体输出 | 不伪造能力、速度或数据 |
| 硬件或物件 | 实物照片、合法模型、3D 镜头 | 比例、材质、细节与事实一致 |
| 概念解释 | 原创插画、系统图、类比 | 每个图形对应一个明确概念 |
| 数学与数据 | 方程、图表、趋势标注 | 坐标、来源、量纲与结论正确 |
| 口播与访谈 | 用户录音、字幕、关键词 | 不遮挡人脸，字幕与实际声音对齐 |
| 品牌短片 | 品牌资产、受控色彩、少量有意图的动作 | 语气一致，结尾清楚 |

不要把其他项目的互动量、剪辑频率或平均 BPM 当成当前项目的成功保证。用户的内容与实际反馈是主要依据。
